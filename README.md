# Coffee Quiz · 咖啡知识自测工作台

单文件 HTML，零外部依赖。题库内嵌 295 道题（合并自示例站的 177 题 SCA 杯测/烘焙/豆种等 + 桌面 PDF「2026 SCA Q Grader 理论复习题库」的 118 题 CVA/感官科学/杯测制备/处理法等），26 个分类。

## 功能
- 抽题档位：10/20/30/50/全题库（295），可按章节筛选
- 答题即时判分、章节正确率、错题回顾、重练错题
- 历史成绩（按正确率排名）+ 金/银/铜徽章 + 每条记录独立签名（支持编辑/清除）
- 点击签名徽章：弹出该签名的历史排名卡（轮次/平均/最佳/最差/全部轮次）
- 点击「📜 历史成绩」标题：弹出全量历史成绩大卡
- 数据备份：导出 JSON / 导入恢复 / 清空本地
- localStorage 持久化（`wb_quiz_history_v1` + `wb_quiz_history_log_v1` + `wb_quiz_last_sig`）

## 使用
直接打开 `index.html` 即可，无任何依赖。

## 部署
已配置为 Cloudflare Pages 静态站点项目，推送到 GitHub 后由 Pages 构建部署。
